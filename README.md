## 🌌 Overview

> *"Big architectures are born from small scripts written late at night."*

**TaskFlow** is an obsidian-themed, local-first desktop productivity stream engineered with **Python**, **CustomTkinter**, and **SQLite3**. 

Designed with zero external asset dependencies, sub-millisecond local queries, and keyboard-driven ergonomics, it acts as a lightweight daily sprint companion that never loses state between reboots.

### ⏳ An 8th-Grade Milestone

This project represents the **very first standalone desktop GUI application I ever engineered back in Grade 8**. 

Long before touching enterprise clouds, distributed microservices, or full-stack web architectures, this tiny engine was my sandbox for:
* 🔄 **Event loops & Tkinter lifecycle**
* 🧱 **Local relational persistence with SQLite**
* 🎨 **Designing dark-mode interfaces** before dark mode was standard
* ⚡ **Real-time UI component re-renders**

## ✨ Key Capabilities

| Feature | Description | Highlight |
| :--- | :--- | :---: |
| 🌙 **Obsidian Dark Theme** | Curated high-contrast palette (`#08070A`) with crimson accent borders | Aesthetic |
| ⚡ **Zero-Asset Engine** | Native CustomTkinter vector glyphs render in-engine without missing `.png` errors | Lightweight |
| 💾 **Self-Provisioning DB** | Automatically creates and verifies `todo.db` schema with migration safety guards | Local-First |
| ⌨️ **Keyboard Ergonomics** | Fluid rapid-fire input with automated key-listener bindings | Ergonomic |
| 📜 **Elastic Stream** | Auto-stretching scroll container engineered to handle dozens of active tasks | Responsive |
| 🎯 **Live Telemetry** | Dynamic task completion counters (`Done / Total`) updating in real-time | Feedback |

## ⌨️ Keyboard Shortcuts

Speed through your day without taking your hands off the keyboard:

| Action | Keybinding | What it does |
| :--- | :---: | :--- |
| **Submit / Save** | <kbd>Enter ↵</kbd> | Adds new task or commits current edit |
| **Cancel Edit** | <kbd>Esc</kbd> | Exits active edit mode and resets the input box |
| **Focus Search** | <kbd>Ctrl</kbd> + <kbd>F</kbd> | Jumps directly to filter stream |
